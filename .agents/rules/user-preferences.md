# Regras e Preferências do Usuário

- **Controle de Versão (Git)**:
  - **NUNCA** faça commits ou push automáticos sem a solicitação explícita do usuário.
  - Deixe sempre o usuário testar e validar localmente todas as alterações visuais e de código primeiro.
  - Apenas execute comandos `git commit` ou `git push` quando o usuário pedir expressamente: "faça o commit", "suba para o git" ou equivalente.
